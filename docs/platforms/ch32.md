# CH32 RISC-V Bridge (`barefoc-ch32`)

`barefoc-ch32` brings BareFOC support to WCH QingKe RISC-V microcontrollers (specifically the CH32V307 series) via `ch32-hal`.

---

## Capabilities

- **Complementary 6-PWM**: Uses Advanced Timer `TIM1` with hardware dead-time insertion for discrete 3-phase MOSFET inverters.
- **Monotonic System Clock**: Uses the 64-bit QingKe SysTick timer (`SysTick_LOAD`) to provide high-precision microsecond timestamps for `Clock`.
- **ADC Triggering**: Synchronizes ADC injected conversions with PWM center points for phase current measurement.
- **PFIC Reset Integration**: Triggers software system resets via the Programmable Fast Interrupt Controller (PFIC).
- **Hardware Electronic Signature (`Ch32Uid`)**: Reads the 96-bit factory ESIG unique identifier from system memory (`0x1FFF_F7E8`), implementing `barefoc::traits::HardwareUid` with zero-allocation stack formatting.
