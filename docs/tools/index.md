# Tools & Utilities

BareFOC provides developer utilities and graphical tools for configuration, tuning, calibration, and flashing.

---

## Available Tools

- [**bareConfig Workbench**](/tools/bareconfig/): Unified graphical workbench for flashing, calibrating, tuning, and monitoring BareFOC hardware and BareBoot bootloaders on Desktop, Android, and WebAssembly.
- [**Master Controller SDK**](/tools/master/): `#![no_std]`, zero-heap host-side SDK (`barefoc-master`) for discovering, configuring, and controlling multi-node BareFOC actuators.
